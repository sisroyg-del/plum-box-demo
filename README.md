# plum box · דמו מוצר

דמו למערכת השכרת אקססוריז לימי צילום של מעצבות פנים.

| ממשק | קישור | פרטי כניסה |
|---|---|---|
| אתר הלקוחות | `shop.html` | לקוחה לדוגמה: demo@plumbox.co.il / 1234 |
| ממשק המפעיל | `admin.html` | סיסמה: plum |
| דף פתיחה | `index.html` | |

## מה יש בדמו

1. **ממשק מפעיל**: העלאת תמונות וסידורן בגרירה, ניהול מוצרים (שם, תיאור חופשי, מאפיינים, מלאי, מחיר השכרה, משך השכרה, מחיר קנייה), חבילות עם מחיר ומשך משלהן, קטגוריות בשלוש קבוצות סינון (סוג, צבע, חומר), באנרים, הזמנות ופניות ייעוץ.
2. **אתר לקוחות**: באנר מתחלף, שורות גלריה בסגנון נטפליקס, סינון וחיפוש, עמוד פריט וחבילה (כולל תמונות הפריטים שבחבילה), בחירת תאריכים בסגנון הזמנת מלון (מינימום 3 ימים), סל, הרשמה/כניסה והזמנה.
3. **לוח זמינות** (`assets/js/inventory.js`): מקור האמת למלאי. כל הזמנה נועלת יחידות לכל ימי ההשכרה; חבילות מפורקות לפריטים שבתוכן; כל יחידה פיזית (#1, #2…) משויכת להזמנה מסוימת. במפעיל יש מפת חום חודשית, פירוט לפי יום וחסימות ידניות.

## מגבלות הדמו

אין שרת: הנתונים נשמרים ב-IndexedDB של הדפדפן. שינויים במפעיל מופיעים באתר הלקוחות באותו דפדפן (גם בלשונית אחרת), אבל לא אצל משתמשים אחרים. השלב הבא: חיבור לבסיס נתונים משותף (למשל Supabase) ותשלום.
